# Supported Themes and UI Technologies for Remote Theming

Remote theming delegates the theme build to the UI Theme Designer service on Cloud Foundry. Only themes that can be built by this service are supported in a remote theming scenario.

The following themes and UI technologies are supported in a remote theming scenario:

-   Themes based on Horizon, Quartz, or Belize
-   The UI technologies UI5, UR, and Base in their versions available in cloud provisioning. To find out which versions are currently in cloud provisioning, see the section *To List Available UI Technologies and Their Versions* in [Determining Theme ID and Theme Root](../determining-theme-id-and-theme-root-c612d38.md).

The following is not supported in a remote theming scenario:

-   Themes based on themes older than Belize, for example, Blue Crystal, Goldreflection, or Tradeshow
-   The UI technologies WebClient UI \(CRM WebUI\) and NetWeaver Business Client \(NWBC\)
-   Versions of UI5, UR, and Base that are not in cloud provisioning
